## 3. README.md: contenido obligatorio (en inglés, claro y breve)

1. **Nombre y una frase:** "ASTRA HEALTH — an offline-first educational prototype for monitoring astronaut health with intermittent connectivity and delayed Earth–ship communications (NASA Space Apps Challenge 2026)."
2. **Aviso visible al inicio:**
   - *Educational prototype — not a medical device.*
   - *Does not replace professional care.*
   - *Not endorsed by NASA.*
   - *All data is fictional.*
   - *The mission clock and communication delay are simulated.*
3. **Qué hace:** los 8 pasos del recorrido (PROJECT_SPEC §13), en una lista corta y en lenguaje neutral, **sin diagnósticos**.
4. **Cómo funciona:**
   - monorepo (`apps/web`, `apps/api`, `packages/contracts`, `packages/health-engine`);
   - PWA offline-first con IndexedDB y un service worker;
   - outbox con sincronización idempotente;
   - canal con `deliverAt` y visibilidad filtrada en el servidor;
   - comparación personal **explicable** (mediana de hasta 7 registros previos comparables, sin umbrales clínicos).
5. **Retraso simulado:**
   - el perfil `MARS_TRANSIT` usa **20 minutos simulados de un sentido**, dentro del rango real de **4 a 24 minutos** según NASA (citar la fuente);
   - en la demo el reloj va **60 veces más rápido**, así que son unos **20 s reales**.
6. **Cómo correrlo** (Windows PowerShell; requisitos: Node 26 y npm 11):
   - `npm ci`;
   - copiar `apps/api/.env.example` a `apps/api/.env` y `apps/web/.env.example` a `apps/web/.env`;
   - `npm run db:setup`, `npm run build`, `npm run start:api` y, en otra terminal, `npm run preview:web`;
   - abrir `http://localhost:4173/?role=ship` (nave) y `http://localhost:4173/?role=earth` (Tierra), y explicar que el "demo mode" **no es un inicio de sesión**;
   - cómo simular la pérdida de enlace con el modo *Offline* de las herramientas de desarrollo;
   - `npm test`.
7. **Limitaciones conocidas:**
   - sin autenticación real;
   - la guía de emergencia es solo un *design pending*, porque no hubo revisión médica competente;
   - no hay reglas clínicas;
   - el estado de ánimo no se compara;
   - no hay mensajes libres;
   - no cambiar el factor del reloj con la nave desconectada.
8. **Fuentes:**
   - NASA, *Space Communications: 7 Things You Need to Know* — https://www.nasa.gov/missions/tech-demonstration/space-communications-7-things-you-need-to-know/
   - NASA Space Apps Challenge 2026 — https://www.spaceappschallenge.org/2026/
9. **Uso de IA:** el desarrollo se hizo con asistentes de IA (Claude Code y Codex), y el equipo revisó cada cambio, con pruebas automatizadas.
10. **Equipo** y **licencia:** Apache-2.0 (ver `LICENSE`).
